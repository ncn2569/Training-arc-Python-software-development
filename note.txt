Nguyên tắc chung là:

Tên file, thư mục và class nên kể cùng một câu chuyện.

Ví dụ:

agent/
├── context_manager.py
├── tool_executor.py
├── memory_store.py

Bên trong:

# context_manager.py
class ContextManager:
    ...
# tool_executor.py
class ToolExecutor:
    ...
# memory_store.py
class MemoryStore:
    ...

Nhìn là đoán được ngay:

context_manager.py  → ContextManager
tool_executor.py    → ToolExecutor
memory_store.py     → MemoryStore

Không cần mở file.
